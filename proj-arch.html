KAMPUNG

URBAN DESIGN FRAMEWORK

This project is a reimagining of Kampung Baru in Kuala Lumpur.

Built around supporting local construction heritage and techniques, the project densifies the area in a healthy and historic manner.

The project consists of architectural design and urban design proposals, existing in multiple scales.

The system consists of a modular adaptive urban fabric.

This project was completed as coursework for DES 401
